매칭 원칙 (v4.0)

v4부터는 단순 키워드 매칭이 아니라 3단계 의미 기반 매칭으로 작동합니다.

1단계: 의도 개념 추출

질의를 16개 도메인 개념(효능·가공·유전육종·재배·병해방제·축산·식품·환경 등)에 매핑합니다. 예: "농산물별 효능 정보" → 의도 = 기능성·효능 + 정보·DB. "농산물"은 너무 일반적이라 단독 의도가 되지 않습니다.

2단계: TF-IDF 자동 가중

코퍼스 내 흔한 단어(연구·관리·개발·분석은 25-49% 전문가에 등장)는 자동으로 가중치 ↓, 드문 단어(효능·항산화·면역)는 가중치 ↑.

3단계: 개념 매칭 + 의도 보너스

전문가별로 현재업무·NTIS텍스트에서 추출된 개념 프로필과 질의 의도를 비교. 의도 개념과 일치하면 추가 보너스 ×2~×3.

왜 이렇게 매칭하나

"농산물 효능"으로 검색했을 때, "농산물 재배 자동화" 전문가가 "농산물"이라는 단어로 매칭되는 문제를 방지합니다. 대신 "기능성·효능" 개념이 일치하는 전문가가 우선 추천됩니다.

데이터 출처: collab_matching_MASTER.csv (2,069명, 현재업무·NTIS 통합). GPT 협업매칭 지침 v5 적용.
